# ABB RobotStudio Tutorial Stations

This repository contains learning projects created with **ABB RobotStudio**.  
The goal is to demonstrate basic **industrial robot programming, simulation, and Smart Component logic**.

## Contents

The repository currently includes three tutorial stations:

- **First tutorial station** – Basic robot movement and target teaching  
- **Second tutorial station** – Pick & Place workflow with RAPID programming  
- **Third tutorial station** – Smart Component gripper with attach/detach logic

## Technologies

- ABB RobotStudio
- RAPID programming
- Smart Components
- Industrial robot simulation

## Purpose

The projects are designed for **learning industrial robotics fundamentals**, including:

- Robot motion programming
- Tool and workobject usage
- Digital I/O control
- Smart Component interaction
